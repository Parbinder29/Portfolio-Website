# Parbinder Singh · Portfolio

Personal portfolio of Parbinder Singh, B.Tech CSE at Central University of Jammu, working across AI/ML, IoT and full-stack web.

**Live:** https://portfolio-website-mu-nine-43.vercel.app/

## What's on it

- **Work:** ATMSF (fault-tolerant multi-sensor fusion), a patented smart irrigation system, and EfficientNetV2 garbage classification
- **Experience:** UVIN Group, Edunet Foundation (AICTE · Shell Skills4Future) and IIT Jammu
- **Honours:** Hacktack25, Innovate25, design patent 450458-001, NCC 'C' certificate and the All India Thal Sainik Camp
- **Skills:** with a filter that highlights what each project used

## Built with

Next.js 16 (App Router) and TypeScript, plain CSS, and one variable font (Archivo). There are no UI or animation libraries; the interactive pieces are small React components.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

## Editing content

- All text and links (projects, experience, honours, skills, resume) live in `components/data.ts`.
- The accent colour is set once at the top of `app/globals.css` (`--accent` and `--accent-rgb`).

Pushes to `main` deploy automatically on Vercel.
